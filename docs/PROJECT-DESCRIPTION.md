# Project description

## GitHub About

A lightweight native macOS PDF reader for English papers, with selection-based translation, three-color highlighting, typewriter notes, and document tabs. Supports Baidu Translate and custom model APIs.

## Longer description

Light Reader is a focused macOS app for reading English research papers. Select a passage to see its Chinese translation in a sidebar, highlight or underline important text, and add handwritten-style typewriter notes directly to the PDF. Open multiple papers in tabs or separate windows and save annotations back to standard PDF files.

Built with Swift, SwiftUI, AppKit, and PDFKit, Light Reader works with your own Baidu Translate credentials or a configurable Chat Completions-compatible model endpoint. Documents stay on your Mac, and only the text you select is sent for translation. Its goal is to make reading and annotation comfortable without the complexity of a full document-management suite.
